# iPhone Studio — прототип

Windows 11 + iOS 16+. USB через Apple Mobile Device / usbmux. Без облака.

## Windows
1. Установите Python 3.11+ с python.org и Apple Devices из Microsoft Store (драйверы Apple).
2. Подключите iPhone кабелем с передачей данных, разблокируйте, подтвердите «Доверять».
3. Запустите Windows/Start.bat. Первый запуск требует интернет для Python-зависимостей.
4. После установки iOS-клиента откройте его на телефоне и нажмите «Подключить USB» на ПК.
5. Выберите физическую камеру, разрешение, FPS, нажмите «Применить настройки». Затем запись и стоп. MOV автоматически копируется в выбранную папку.

## iPhone (требуется сборка на Mac)
В архиве Swift-исходник, а не подписанный IPA. На Mac с Xcode создайте новый iOS App (SwiftUI), удалите файлы App и ContentView и добавьте Studio.swift. В Info добавьте Privacy - Camera Usage Description, Microphone Usage Description, Local Network Usage Description. Deployment target iOS 16+. Альтернатива: установить XcodeGen и выполнить `xcodegen generate` в iOS, открыть полученный xcodeproj. В Signing & Capabilities выберите свою команду Apple ID и уникальный Bundle ID. Подключите iPhone к Mac, при необходимости включите Developer Mode, запустите приложение из Xcode. Бесплатная личная подпись обычно требует повторной установки через 7 дней. Затем подключите телефон к Windows.

## Ограничения
Это исходный прототип, не проверенный на реальном iPhone или Windows. Сборка iOS и подпись обязательны. Предпросмотр JPEG примерно до 10 кадров/с, до 960 px по ширине; видео записывается в полном выбранном качестве локально на телефон, затем копируется через USB. Свободное место нужно на обоих устройствах. Не закрывайте приложение и не отключайте кабель до окончания копирования. Поддерживаемые режимы зависят от модели и объектива; неподдерживаемые разрешения/FPS отклоняются, ручные значения ограничиваются диапазонами камеры. Настройки применяются до записи, не во время неё. Ориентация видео по умолчанию не настраивается. Файлы на телефоне временные, не удаляются автоматически после передачи. Если передача прервалась, последний файл доступен по GET /video до перезапуска iOS-клиента; например curl.exe http://127.0.0.1:18765/video -o recovered.mov при активном USB-пробросе.
