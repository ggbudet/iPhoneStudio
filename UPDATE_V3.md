# iPhone Studio v3

## Обновление
1. Закройте Windows-приложение. Скопируйте содержимое архива в существующий репозиторий, сохраняя .git. Commit, Push origin, Actions, Build iPhone Studio IPA. Скачайте артефакт и установите IPA через Sideloadly с прежним Bundle ID. Версии Windows и iOS должны совпадать (протокол 3).
2. Запустите Windows/Start.bat, чтобы установить новые зависимости. Подключите USB как раньше.
3. Настройки отправляются автоматически через 120 мс после последнего изменения. Ручные поля доступны после отключения соответствующего автоматического режима. Во время локальной записи можно менять ручные параметры, но не объектив, разрешение и FPS. После ошибки исправьте параметры; статус справа показывает результат.

## Виртуальная камера OBS
1. Скачайте https://github.com/schellingb/UnityCapture (Code → Download ZIP). Распакуйте в постоянную папку, например C:\Tools\UnityCapture. Запустите Install\Install.bat от администратора. Не удаляйте папку после установки. Unity Editor не нужен.
2. Перезапустите OBS. В iPhone Studio подключите телефон, выберите OBS FPS (30 или 60), включите виртуальную камеру.
3. В OBS добавьте источник «Устройство захвата видео», устройство Unity Video Capture. Укажите пользовательские 1920x1080 и выбранный FPS. При проблеме попробуйте формат по умолчанию.
4. Виртуальная камера передает только видео, без сетки предпросмотра и без звука. Микрофон добавляется в OBS отдельно. Запись оригинального MOV на телефон по-прежнему поддерживает звук.

Выход OBS фиксирован 1920x1080, 30/60 FPS; при другом соотношении сторон добавляются черные поля. Частота вывода не гарантирует столько же уникальных кадров: повторяется последний кадр при нехватке новых. При отсутствии свежих кадров более двух секунд вывод черный, затем восстанавливается автоматически. USB-проброс перезапускается при завершении процесса во время потока. 4K запись не означает 4K виртуальную камеру.

Проверен синтаксис Python и Swift, но не выполнены сборка iOS, тест DirectShow на Windows и тест реального телефона. Unity Capture — отдельный бесплатный сторонний драйвер, не включен в архив. Не запускайте одновременно два приложения, использующих один выход Unity Capture.
