# Сборка без Mac
1. Создайте репозиторий на github.com (можно приватный; учитывайте лимит Actions).
2. Загрузите содержимое этого архива в корень репозитория, включая скрытую папку .github. Удобнее через Git или GitHub Desktop.
3. Actions → Build iPhone Studio IPA → Run workflow. После успешной сборки скачайте артефакт iPhoneStudio-IPA и распакуйте его.
4. Установите IPA через Sideloadly (https://sideloadly.io/) с личной подписью Apple Account. Следуйте требованиям программы к драйверам Apple. При необходимости включите Developer Mode на iPhone. Бесплатную подпись обычно нужно обновлять каждые 7 дней.
5. Запустите приложение на iPhone, подтвердите разрешения, затем Windows/Start.bat на ПК и подключение USB. См. README.md.
